# Documentation historique

Ce répertoire conserve les documents qui ne décrivent plus l’état courant.
Ils restent versionnés pour la traçabilité des décisions et des développements.

## Classement

- `audit/` : audits et revues datées ;
- `reports/` : rapports d’implémentation par ancienne fonctionnalité ;
- `recovery/` : inventaires, architecture cible et clôtures des Phases 0/0.5 ;
- `guides/` : guides remplacés après la migration vers `src/` ;
- `workflow_ai_coding.md` : ancien workflow de développement assisté par IA ;
- `reference_cases_pre_phase05.md` et `tool_maturity_pre_phase05.md` :
  anciennes versions consolidées depuis dans la documentation canonique.

## Règle de lecture

Ces fichiers peuvent contenir des imports, chemins, nombres de tests ou
responsabilités obsolètes. Ne pas les utiliser comme guide d’exécution.

La documentation active commence dans [`../README.md`](../README.md).
